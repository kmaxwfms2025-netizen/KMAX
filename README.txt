KMAX WORKFORCE AND MANPOWER SOLUTIONS — WEBSITE STARTER
======================================================

FILES
- index.html: website pages/content
- styles.css: responsive navy-blue/cyan styling
- script.js: mobile navigation, job search, WhatsApp job enquiry and employer form
- assets/: KMAX banner and cropped logo based on the image supplied in chat

IMPORTANT
- This is a static starter website. It does not save candidate applications in a database.
- Job cards are sample role categories, not confirmed live vacancies. Update them before publishing.
- Job application buttons open WhatsApp with the role prefilled. Candidates can then send their own message and resume in WhatsApp.
- Employer enquiry form opens WhatsApp with form details filled in; user must tap Send.
- WhatsApp number is set to +91 6364 777 638.
- No construction or security guard listings are included.
- Google Fonts is optional; the site uses fallback fonts if unavailable.

PUBLISH FREE WITH GITHUB PAGES
1. Extract this ZIP on your computer.
2. Sign in or create a free account at https://github.com
3. Create a new public repository, e.g. kmax-workforce-website.
4. Upload index.html, styles.css, script.js, README.txt and the complete assets folder.
5. In the repository, open Settings → Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Choose the main branch and /(root), then Save.
8. Wait for GitHub Pages to publish. The site address will look like https://YOUR-USERNAME.github.io/kmax-workforce-website/
9. Open the URL on a phone and test all links and forms.

ALTERNATIVE: NETLIFY DROP
1. Extract the ZIP.
2. Visit https://app.netlify.com/drop and sign in if prompted.
3. Drag the extracted website folder (the folder containing index.html) onto the page.
4. Use the generated free netlify.app URL to test your site.

FREE HOSTING LIMITATIONS
- A custom domain such as kmax.in normally costs money to register.
- This version does not have a secure database, admin panel, resume upload storage or email notifications.
- For real vacancy management and stored applications, add a backend or connect a suitable form/database service before collecting personal data.
- Review privacy, consent, and applicable legal requirements before collecting candidate details.
